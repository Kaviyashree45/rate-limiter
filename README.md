# Token Bucket Rate Limiter Service

A production-ready Rate Limiter Service built using Spring Boot.

## Features
- Token Bucket Algorithm
- Sliding Window Algorithm
- Thread-safe
- PostgreSQL Persistence
- Redis (Upcoming)

## Tech Stack
- Java 21
- Spring Boot
- PostgreSQL
- Gradle
